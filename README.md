
# PersonalHost

A simple website advertising self-hosted website hosting services.

## Hosting plan

- Price: ₹5,000 per month
- RAM: 2 GB
- CPU: 1 CPU
- Storage: 15 GB

## Deployment

Deploy using the Dockerfile with a container port of 80.

## Before publishing

Replace YOUR_EMAIL@example.com in index.html with your actual contact email.
